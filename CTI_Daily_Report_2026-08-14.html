1. Executive Summary

Отчётный период характеризуется публикацией крупнейшего в 2026 году набора обновлений Microsoft Patch Tuesday (398–421 CVE, по разным подсчётам вендоров), активной эксплуатацией нескольких критических уязвимостей «нулевого дня» (Windows AFD.sys, Metabase, VMware vCenter), продолжающейся кампанией DeadLock с блокчейн-инфраструктурой C2, а также фишинговыми кампаниями северокорейских (Operation Dream Job) и российских (Sandworm/UAC-0145) государственных группировок, использующих фейковые предложения о трудоустройстве.

Топ-5 критических событий дня

  1. CRITICAL Microsoft Patch Tuesday, август 2026 — устранено 398 CVE (42 критических), включая активно эксплуатируемый 0-day CVE-2026-68820 (Windows AFD.sys, EoP) и критические RCE CVE-2026-62815 (MS QUIC, CVSS 9.8), CVE-2026-62893 (Windows Deployment Services, CVSS 9.8), CVE-2026-62878 (Windows DNS Server, CVSS 9.8).
  2. CRITICAL Metabase — unauthenticated SQL Injection 0-day (CVE-2026-72898, CVSS 10.0) — активно эксплуатируется в дикой природе для получения полного административного доступа; добавлена в CISA KEV со сроком устранения для федеральных агентств США до 14.08.2026.
  3. CRITICAL VMware vCenter — Directory Traversal (CVE-2026-59310, CVSS 9.8) — глобальная кампания эксплуатации, зафиксировано 361 IP-адрес жертв в 47 странах; используется для развёртывания reverse SSH и закрепления через вредоносные cron-задания.
  4. HIGH DeadLock Ransomware — устойчивая к блокировке инфраструктура на блокчейне Polygon и сети Session; свыше 80 жертв (преимущественно в Европе: IT, добывающая промышленность, транспорт, производство).
  5. HIGH Государственные фишинговые кампании под видом трудоустройства — Sandworm/UAC-0145 (трояны WireGuard/SopraVPN против украинских системных администраторов) и северокорейская Operation Dream Job (фейковые вакансии Lockheed Martin/Enveil), эксплуатирующая, среди прочего, CVE-2026-68820.

Главные кампании злоумышленников

  • DeadLock (финансово мотивированная, RaaS) — Rust-энкодер, C2 через смарт-контракты Polygon, чат с жертвами через Session, эксфильтрация на Wasabi Cloud.
  • Sandworm / UAC-0145 (state-sponsored, РФ, связана с GRU) — фейковый рекрутер «Atlas Business Group», интервью в Zoom, троянизированный клиент WireGuard «SopraVPN», доставка PowerShell-полезной нагрузки украинским системным администраторам.
  • Operation Dream Job (state-sponsored, KND) — фейковые вакансии от имени Lockheed Martin и Enveil, кража данных и установка вредоносного ПО, использование CVE-2026-68820.
  • BdThemes Supply Chain Attack
  • QUIRSO-кластер

Рекомендации

Для SOC

  • Настроить детектирование попыток эксплуатации CVE-2026-68820 (аномальные вызовы afd.sys, повышение привилегий до SYSTEM), CVE-2026-72898 (нетипичные запросы к /api/session/reset_password) и CVE-2026-59310 (path traversal к Syslog vCenter, появление reverse_ssh, подозрительные cron-задания).
  • Мониторить исходящие соединения к инфраструктуре Polygon/Session, характерные для DeadLock.
  • Расширить правила фишинг-детектирования на сценарии «фейковый рекрутер → Telegram/Zoom → запрос установки VPN-клиента».

Для Blue Team

  • Провести threat hunting на предмет закрепления через reverse_ssh и нетипичные cron-задания на серверах vCenter.
  • Проверить журналы Metabase на признаки несанкционированного сброса паролей и создания новых admin-аккаунтов.
  • Аудит установленных VPN-клиентов на рабочих станциях ИТ-персонала (в т.ч. неофициальные сборки WireGuard).

Для Vulnerability Management

  • Приоритет 1 (24–48 часов): Metabase (CVE-2026-72898), VMware vCenter (CVE-2026-59310), Windows AFD.sys (CVE-2026-68820).
  • Приоритет 2 (7 дней): остальные критические Windows CVE из Patch Tuesday (MS QUIC, WDS, DNS Server), критические advisories Cisco Catalyst SD-WAN и IOS XE от 05.08.2026.
  • Обеспечить включение всех новых записей CISA KEV в цикл патч-менеджмента с SLA ≤ 48 часов для федеральных/критичных систем.

Администраторам Windows

  • Немедленно установить кумулятивные обновления августа 2026 (KB5121003 / KB5120240 для Windows 11; KB5120249 для Windows 10 ESU).
  • Отдельное внимание — серверам с ролями DNS Server и Deployment Services (критические RCE с CVSS 9.8).
  • Учитывать публикацию эксплойта «ShieldBreak» для Microsoft Defender, выпущенного вскоре после Patch Tuesday.

Администраторам Cisco

  • Применить обновления от 05.08.2026 для Catalyst SD-WAN (CVSS 9.9) и IOS XE (CVSS 9.8) в приоритетном порядке.
  • Подготовиться к очередному пакету advisories, запланированному на 19.08.2026 (BroadWorks, промышленные коммутаторы, RoomOS, Secure Firewall).

Администраторам WordPress

  • Проверить используются ли плагины BdThemes — семь плагинов временно сняты с публикации в каталоге WordPress.org; при обнаружении признаков компрометации — полный форензический аудит, ротация ключей и инвалидация сессий.
  • Обновить Ajax Search Lite до версии 4.14.5+ (CVE-2026-28139, CVSS 9.8, unauthenticated PHP Object Injection).

2. Windows

Microsoft Patch Tuesday — август 2026

Дата публикации: 11.08.2026  |  Источники: SecurityWeek, Qualys, Tenable, CrowdStrike, cybersecuritynews.com, ZDI, Talos, Krebs on Security, The Hacker News

Краткое описание: Microsoft выпустила крупнейший в 2026 году пакет обновлений безопасности, устранив от 394 до 421 CVE (данные источников расходятся — отмечено как расхождение) — 42–62 из них критические. Один 0-day активно эксплуатировался до выпуска патча.

⚠️ Противоречие в данных: количество устранённых CVE варьируется по источникам (Tenable/SecurityWeek — 398/421; cybersecuritynews.com — 394; ZDI/Talos учитывают дополнительные сторонние advisories). Krebs on Security связывает рост числа находок с использованием ИИ в процессе поиска уязвимостей внутри Microsoft.

Технические детали:

  • CVE-2026-68820 — use-after-free в Windows Ancillary Function Driver for WinSock (afd.sys), эксплуатируется для повышения привилегий до SYSTEM. Активно эксплуатируется в атаках (в т.ч. Operation Dream Job).
  • CVE-2026-62815 — критическая RCE в Microsoft QUIC, CVSS 9.8, эксплуатация без аутентификации и без взаимодействия пользователя.
  • CVE-2026-62893 — критическая RCE в Windows Deployment Services, CVSS 9.8.
  • CVE-2026-62878 — критическая RCE в Windows DNS Server, CVSS 9.8.
  • CVE-2026-62832 — EoP в Windows User Profile Service, CVSS 7.8, локальный вектор, получение прав ADMINISTRATOR.
  • CVE-2026-62696 — EoP в Windows Program Compatibility Assistant Service, получение SYSTEM.
  • CVE-2026-72971 — tampering в Windows Container Isolation FS Filter Driver (unionfs.sys), CVSS 5.5.

Затронутые версии: Windows 10 (ESU), Windows 11 23H2/24H2/25H2, Windows Server (актуальные поддерживаемые версии).

4. WordPress

BdThemes — атака на цепочку поставок (Supply Chain)

Дата публикации: ~08.08.2026 (плагины закрыты в каталоге 07–08.08.2026)  |  Источник: The Hacker News, Wordfence

Краткое описание: Скомпрометированный JSON-фид BdThemes использован для эксплуатации XSS-уязвимостей в семи плагинах WordPress, что приводило к созданию поддельных административных учётных записей и установке PHP web shell без необходимости обновления самих плагинов.

Технические детали: Вредоносный контент доставлялся через удалённый JSON-фид, используемый плагинами для обновления динамических данных (шаблоны, уведомления); инъекция XSS-payload приводила к выполнению административных действий в контексте залогиненного администратора.

Затронутые версии: семь плагинов BdThemes (сняты с публикации в каталоге WordPress.org на период «полной проверки»)

PoC: не публиковался  |  Эксплойт: да, в дикой природе  |  Активная эксплуатация: да

MITRE ATT&CK: T1195.002 (Supply Chain Compromise: Software Supply Chain), T1059.007 (XSS/JS execution)

Официальные рекомендации: The Hacker News

Критический бэкдор в плагине WordPress (20 000+ сайтов)

Дата публикации: конец июля / начало августа 2026 (Wordfence firewall для premium — 28.07.2026, для free-tier — 27.08.2026)  |  Источник: GBHackers, Wordfence

Краткое описание: Обнаружен бэкдор в популярном плагине, позволяющий полный захват учётной записи администратора. Вредоносная версия распространялась ограниченно, однако все сайты с уязвимой версией плагина следует считать потенциально скомпрометированными.

Наличие PoC: нет данных  |  Активная эксплуатация: подтверждена ограниченно

Mitigation: немедленное удаление плагина, аудит всех учётных записей, ротация ключей аутентификации, инвалидация сессий, полный форензический анализ.

Ajax Search Lite — Unauthenticated PHP Object Injection

CVE: CVE-2026-28139  |  CVSS: 9.8 (Critical)  |  Источник: Patchstack

Затронутые версии: до 4.14.4 включительно  |  Патч: 4.14.5

Описание: Неаутентифицированная PHP Object Injection, потенциально ведущая к RCE через цепочки POP-гаджетов при наличии подходящих зависимостей на сайте.

Mitigation: обновление до версии 4.14.5 или выше в приоритетном порядке.

7. Мессенджеры: Telegram / Viber / WhatsApp / Signal

«Careless Whisper» — атака по таймингу delivery receipts

Источник: University of Vienna / SBA Research (RAID 2025 Best Paper)  |  Предварительная информация / академическое исследование

Описание: Уязвимость на уровне протокола, связанная с анализом времени доставки receipt-подтверждений, потенциально позволяющая деанонимизировать/отслеживать пользователей.

DeadLock Ransomware

Дата: публикация анализа Microsoft — 10.08.2026  |  Тип атаки: Ransomware / двойное вымогательство  |  Вредоносное ПО: DeadLock (Rust-энкодер)

Цель: преимущественно европейские организации: IT, добывающая промышленность, транспорт, производство, гостиничный бизнес, потребительские товары (~80 жертв на июль 2026)

Первичный вектор: точно не раскрыт в открытых источниках на момент отчёта

Методы закрепления/устойчивости инфраструктуры: хранение конфигурации и leak-site контента в смарт-контрактах Polygon; чат с жертвами через децентрализованную сеть Session; хостинг похищенных файлов на Wasabi Cloud — позволяет менять инфраструктуру C2 без обновления клиента у жертвы и затрудняет takedown правоохранительными органами.

MITRE ATT&CK: T1486 (Data Encrypted for Impact), T1567 (Exfiltration Over Web Service), T1071 (Application Layer Protocol), T1090 (Proxy)

Рекомендации: мониторинг исходящего трафика к инфраструктуре Polygon/Session на конечных точках и периметре; резервное копирование по правилу 3-2-1; сегментация сети для ограничения бокового перемещения.

Источник: Microsoft Security Blog, BleepingComputer

Sandworm / UAC-0145 — трояны WireGuard через фейковые интервью

Дата: кампания активна с мая 2026, публикация анализа — 11.08.2026  |  Тип атаки: Целевой фишинг / социальная инженерия / trojanized software  |  Вредоносное ПО: «SopraVPN» (троянизированный клиент WireGuard)

APT-группа: Sandworm (APT44, GRU) / суб-кластер UAC-0145

Цель: украинские системные администраторы и IT-специалисты

Первичный вектор: фейковый рекрутер под видом «Atlas Business Group», предложение работы над проектом, связанным с Sopra Steria Bulgaria, перевод переписки в Telegram, интервью в Zoom, установка «корпоративного VPN» под видом технического задания.

Методы закрепления: запуск PowerShell-полезной нагрузки через троянизированный WireGuard-клиент, обеспечивающий удалённый доступ к скомпрометированной машине сисадмина.

MITRE ATT&CK: T1566 (Phishing), T1204 (User Execution), T1195 (Trojanized Software), T1059.001 (PowerShell)

Рекомендации: верификация рекрутеров и работодателей через официальные каналы; запрет установки стороннего ПО «для тестового задания» на корпоративных/личных устройствах с доступом к инфраструктуре; обучение персонала распознаванию сценариев job-offer фишинга.

Источник: The Hacker News, BleepingComputer, The Record

MITRE ATT&CK: T1566 (Phishing), T1068 (Exploitation for Privilege Escalation)

Кампания эксплуатации VMware vCenter (CVE-2026-59310)

Дата: advisory Broadcom — 29.07.2026 (VMSA-2026-0006), начало массовой эксплуатации зафиксировано QUIRSO с 03.08.2026, отчёты об активной кампании — 11–13.08.2026

Тип атаки: Эксплуатация уязвимости в периметровой инфраструктуре виртуализации

Цель: 361 IP-адрес жертв в 47 странах; наиболее пострадавшие — Германия, США, Турция, Иран, Франция (185 из 361 IP)

Первичный вектор: directory traversal в Syslog-сервере vCenter, ведущий к RCE

Методы закрепления: развёртывание вредоносного cron-задания, установка reverse_ssh (открытый инструмент) для организации обратного SSH-туннеля к инфраструктуре атакующих.

MITRE ATT&CK: T1190 (Exploit Public-Facing Application), T1053.003 (Scheduled Task/Job: Cron), T1572 (Protocol Tunneling)

Рекомендации: немедленное применение патча VMSA-2026-0006; аудит cron-заданий на vCenter-хостах; блокировка исходящих SSH-соединений к нетипичным адресам; сегментация management-плоскости.

Источник: The Hacker News, SecurityWeek, Dark Reading
