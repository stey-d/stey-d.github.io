Executive Summary

Отчетный период характеризуется критическим уровнем риска: подтверждена активная эксплуатация нового Windows kernel zero-day (CVE-2026-68820) северокорейской группировкой Lazarus в кампании Operation Dream Job, а также массовая эксплуатация свежераскрытого PoC для обхода аутентификации SharePoint (CVE-2026-55040) в течение суток после публикации. CVE-2026-68820 — Windows AFD.sys (WinSock) 0-day, эксплуатируется Lazarus (Operation Dream Job)

Дата публикации: присвоен CVE 05.08.2026, патч 11.08.2026, раскрытие кампании — 12.08.2026 · Источник: The Hacker News, BleepingComputer, SecurityWeek, SOC Prime, Forbes

Краткое описание: Use-after-free race condition в afd.sys — драйвере ядра, управляющем сокетными операциями WinSock практически для всех приложений Windows. Северокорейская группировка Lazarus эксплуатировала уязвимость минимум 5 недель до выхода патча (артефакт rootkit датирован 07.07.2026) в рамках кампании Operation Dream Job — фишинг через поддельные вакансии на LinkedIn с вредоносным PDF/трояном-«PDF-viewer», устанавливающим бэкдор Troy.

Технические детали: Победа в состоянии гонки над потоками, обращающимися к состоянию сокета без должной синхронизации, дает атакующему kernel read/write примитив и полные привилегии SYSTEM. После эксплуатации разворачивается rootkit FudModule v3.1, отключающий 94 канала мониторинга безопасности (ETW-провайдеры), удаляющий minifilters, останавливающий NT Kernel Logger, обходящий Smart App Control. Таргетируются Windows 11 сборки 26100 и 26200.

Затронутые версии: Windows 10, Windows 11 (в т.ч. 25H2), Windows Server 2025.

PoC: Публично не опубликован (эксплойт использовался в закрытой кампании) · Эксплойт: Да, in-the-wild · Активная эксплуатация: Да, подтверждена

MITRE ATT&CK: T1190 (Exploit Public-Facing Application — вектор через фишинг), T1068 (Exploitation for Privilege Escalation), T1014 (Rootkit), T1562.001 (Impair Defenses: Disable/Modify Tools), T1204.002 (Malicious File)

CVSS: High/Critical (точный балл варьируется по источникам, EoP до SYSTEM) · CWE: CWE-416 (Use After Free)

Официальная рекомендация: Патч включен в August 2026 Patch Tuesday; добавлено в CISA KEV с требованием патчинга федеральных агентств США в течение 2 недель.

Ссылка: The Hacker News · BleepingComputer · SecurityWeek

ShieldBreak — неофициальный Microsoft Defender 0-day (обход патча, SYSTEM-доступ), патча не существует

Дата публикации: 12.08.2026 · Источник: BleepingComputer, The Hacker News, TechCrunch, The Register, cybersecuritynews.com

Краткое описание: Независимый исследователь под псевдонимом «Nightmare Eclipse» опубликовал PoC нового эксплойта «ShieldBreak» вскоре после выхода августовских патчей Microsoft — на фоне открытого конфликта с Microsoft (компания ранее угрожала юридическими действиями исследователю). ShieldBreak — обход исправления для ранее раскрытой уязвимости RoguePlanet (июнь 2026).

Технические детали: Эксплойт использует user-mode callback hook для изменения содержимого файлов во время cloud-hydration сканирования Defender через Cloud Filter API (cfapi), в комбинации с манипуляцией CLFS-логами и символическими ссылками для получения доступа уровня SYSTEM. Для срабатывания требуется включенный Microsoft Defender.

Затронутые версии: Windows 10, Windows 11 (включая последнюю 25H2), Windows Server 2025 — подтверждено работающим на полностью пропатченных системах.

PoC: Да, опубликован публично · Эксплойт: Да · Активная эксплуатация: Не подтверждена официально (Предварительная информация — эксплуатация в реальных атаках пока не зафиксирована, но PoC общедоступен)

MITRE ATT&CK: T1068 (Exploitation for Privilege Escalation), T1562.001 (Impair Defenses)

Официальная рекомендация: Патча от Microsoft на момент публикации отчета нет; является частью серии из 8+ эксплойтов (LegacyHive, RoguePlanet, BlueHammer, RedSun, YellowKey, GreenPlasma, MiniPlasma, UnDefend), выпущенных этим же исследователем с апреля 2026.

Ссылка: BleepingComputer · The Hacker News · The Register

Официальная рекомендация: Патч выпущен Microsoft 11.08.2026 в рамках Patch Tuesday; настоятельно рекомендуется немедленное обновление SharePoint on-prem серверов.

Signal вводит Automatic Key Verification (AKV) — защита от server-level MITM

Дата публикации: 11.08.2026 · Источник: Signal.org (официальный блог), BleepingComputer, The Register, Help Net Security

Краткое описание: Signal представила функцию автоматической верификации ключей, подтверждающую, что end-to-end зашифрованные сообщения достигают только предполагаемого получателя — без личной встречи — путем проверки tamper-evident журнала прозрачности ключей, аудируемого Cloudflare и Trail of Bits.

Технические детали: Функция противодействует подмене ключей на уровне сервера (компрометация инфраструктуры Signal или злонамеренный инсайдер, подменяющий публичный ключ, привязанный к номеру телефона цели). Верификация выполняется независимо самим пользователем, его контактами Signal и сторонними аудиторами — обеспечивая ту же гарантию, что и ручная проверка «security number», но без необходимости личной встречи или второго канала связи. Включается через профиль контакта → «View Safety Number» → «Verify automatically».

Business impact: Позитивное security-развитие, снижает риск MITM-атак на инфраструктуру мессенджера; рекомендуется включить сотрудникам, использующим Signal для чувствительной коммуникации.

Кибератаки

Lazarus / Operation Dream Job — Windows 0-day + FudModule + Troy backdoor

Дата: кампания активна с ~07.07.2026, раскрыта 12.08.2026 · Тип: Целевой шпионаж / APT · Malware: FudModule v3.1 (rootkit), Troy (backdoor), троянизированный PDF-viewer · APT-группа: Lazarus Group (Северная Корея)

Цель: Оборонные и аэрокосмические компании во Франции, Германии, Бразилии, Индии.

Первичный вектор: Фишинг через фальшивые вакансии на LinkedIn (Operation Dream Job) → вредоносный PDF / троянизированный PDF-viewer.

Методы закрепления: Kernel-level rootkit FudModule (отключение ETW-телеметрии, удаление minifilters, обход Smart App Control), бэкдор Troy для удаленного доступа.

MITRE ATT&CK: T1566 (Phishing), T1204.002 (Malicious File), T1068 (Exploitation for Privilege Escalation), T1014 (Rootkit), T1562.001 (Impair Defenses)

Рекомендации: Патч CVE-2026-68820; обучение персонала распознаванию фишинговых вакансий; мониторинг отключения ETW-провайдеров как индикатора компрометации.

Sandworm / UAC-0145 — фейковые собеседования, троянизированный WireGuard «SopraVPN»

Дата: кампания активна с мая 2026, раскрыта CERT-UA 11–12.08.2026 · Тип: Шпионаж / первичный доступ · Malware: Троянизированный WireGuard-клиент «SopraVPN» с поддержкой нестандартной опции SymmetricKey (AES-256-GCM) · APT-группа: Sandworm (APT44 / Seashell Blizzard, ГРУ РФ), кластер UAC-0145

Цель: Системные администраторы и ИТ-специалисты (в первую очередь на Украине).

Первичный вектор: Имперсонация рекрутеров (в т.ч. под видом «ATLAS Business Group»), контакт через платформы поиска работы → Telegram → Zoom-собеседование (с живым англоговорящим собеседником) → доставка «неработающего» WireGuard-конфига → предложение установить троянизированный клиент SopraVPN с SourceForge и поддельного сайта под видом Sopra Steria Bulgaria.

Методы закрепления: Троянизированный VPN-клиент с бэкдор-функцией удаленного выполнения произвольных команд через кастомное поле конфигурации.

MITRE ATT&CK: T1566.002 (Phishing: Spearphishing Link), T1204.003 (Malicious Image/Software), T1059 (Command and Scripting Interpreter), T1071 (Application Layer Protocol — VPN-туннель как C2)

Рекомендации: Проверять легитимность рекрутеров/работодателей независимо; запрет установки VPN-клиентов не из официальных корпоративных источников; мониторинг нестандартных полей в конфигурациях WireGuard.

DeadLock Ransomware — блокчейн-инфраструктура на Polygon

Дата: детальный разбор опубликован Microsoft 10.08.2026, продолжает освещаться 11–12.08.2026 · Тип: Ransomware / двойное вымогательство · Malware: DeadLock (Rust-based encryptor) · Цель: Организации в сфере ИТ, добычи, транспорта, производства, гостиничного бизнеса, товаров народного потребления (преимущественно Европа)

Первичный вектор: Не детализирован в доступных публикациях за отчетный период (требуется дальнейшее уточнение по данным Microsoft Security Blog).

Методы закрепления/устойчивости: Хранение конфигурации C2 и данных leak-сайта в смарт-контракте Polygon blockchain; использование Session (децентрализованный мессенджер) и Wasabi (decentralized storage) для связи с жертвами — снижает зависимость от доменов/серверов, которые могут быть изъяты правоохранительными органами.

MITRE ATT&CK: T1486 (Data Encrypted for Impact), T1567 (Exfiltration Over Web Service), T1071.001 (Web Protocols — через блокчейн-запросы)

Масштаб: 80+ организаций на leak-сайте по состоянию на июль 2026.

Рекомендации: Мониторинг исходящих запросов к RPC-эндпоинтам Polygon как индикатора C2-активности; резервное копирование offline; сегментация сети; готовность к отсутствию единой точки для law-enforcement takedown.

Ссылка: Microsoft Security Blog · BleepingComputer

Unsafe Group — атака на Presentations.AI (Индия)

Дата: 12.08.2026 · Тип: Ransomware / вымогательство данных · APT/группа: «Unsafe» group · Цель: Presentations.AI (технологическая компания, Индия)

Краткое описание: Компания подверглась атаке вымогателей, критические данные под угрозой публикации. Предварительная информация — детали атаки (вектор, объем данных) на момент публикации отчета официально не раскрыты.

IOC

Официальные производители и исследовательские команды на момент подготовки отчета не опубликовали в открытом доступе подробные машиночитаемые индикаторы компрометации (хэши, IP, домены) для ключевых кампаний отчетного периода:

  • Lazarus / CVE-2026-68820 / FudModule / Troy: технический разбор доступен у Microsoft/исследовательских блогов, но конкретные хэши файлов и C2-инфраструктура в проанализированных публикациях не приведены в открытом виде — рекомендуется обращаться к полным техническим отчетам (Microsoft MSTIC, лабораториям AhnLab/Gen Digital и т.п., упоминаемым в первоисточниках).
  • Sandworm / UAC-0145 / SopraVPN: CERT-UA опубликовал детальный технический бюллетень; специализированные платформы threat intel (например, Mallory.ai) содержат IOC «за стеной» — рекомендуется прямой запрос официального advisory CERT-UA.
  • DeadLock ransomware: Polygon smart-contract адрес(а) и связанные домены раскрыты в полном отчете Microsoft Security Blog (см. ссылку выше) — рекомендуется получить их из первоисточника для интеграции в SIEM/TIP.

IP / Domains / URLs / MD5 / SHA1 / SHA256 / Email / Registry / Mutex / YARA / Sigma / Snort / Suricata — не публиковались в достаточном для прямого включения объеме ни одним из проверенных на 12–13.08.2026 источников. Snort-правила для августовского Patch Tuesday доступны в отдельном бюллетене Cisco Talos.
